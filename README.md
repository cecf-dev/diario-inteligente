# Diario Inteligente

Aplicación web de telemetría emocional y prevención de burnout para estudiantes universitarios y desarrolladores. Funciona como un diario inteligente que analiza el texto en tiempo real para extraer carga cognitiva, estrés y patrones de trabajo.

## Stack Tecnológico

- **Frontend:** React.js + Tailwind CSS
- **Backend:** Node.js + Express.js
- **Base de Datos:** PostgreSQL con extensión `pgvector`
- **IA:** Groq API (modelos Llama 3) para inferencia ultrarrápida

## Pantallas

- `/dashboard` — El Radar de Burnout: gráficos de tendencias semanales y alertas generadas por IA.
- `/entry/new` — El Editor de Fricción Cero: captura rápida con análisis asíncrono.
- `/history` — Registro Analítico: línea de tiempo de entradas con etiquetas y nivel de estrés.
